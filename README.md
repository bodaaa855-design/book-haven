# Book Haven

A responsive front-end bookstore demo created for the Information Technology Infrastructure group project.

## How to run
1. Extract `Book_Haven_Website.zip`.
2. Open the `index.html` file in a modern web browser.
3. Internet access is needed for the optional Google Fonts import. The site itself does not need a backend or database.

## Features
- Four navigable sections: Home, Browse Books, About, and My Cart.
- Search books by title or author.
- Filter by category using the dropdown or category pills.
- Add books to the cart, remove them, and view the live subtotal.
- Save and unsave books in a wishlist (current page session only).
- Open an individual book details dialog from its cover or title, with a description and add-to-cart action.
- Responsive layout for desktop and mobile.

## Important scope note
This is a front-end demonstration. Checkout does not process payments, and cart/wishlist data is not stored after the page is refreshed. Prices and book listings are sample data for the student project.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — book data and interactive features
